Tag every ledger of a lake-layout directory, one output set per partition

Usage: xdrcheck-tagger run [OPTIONS] --root <ROOT> --out <OUT>

Options:
      --root <ROOT>              Lake-layout directory (`<partition>/<object>.xdr.zst`)
      --index <INDEX>            `seq<TAB>path<TAB>size` of the ledgers (default: ROOT/index.tsv)
      --out <OUT>                Output directory
      --jobs <JOBS>              Partitions worked at once [default: 8]
      --range <RANGE>            Only ledgers in a..b (inclusive)
      --row-cap <ROW_CAP>        Rows written per (tag, path) and partition [default: 5000]
      --passphrase <PASSPHRASE>  Network passphrase (SAC ids, transaction hashes) [default: "Public Global Stellar Network ; September 2015"]
      --check-size               Check each object's size against the index
  -h, --help                     Print help
