## xdrcheck-judge

Facts from a ledger's own entry changes, and verdicts on an indexer's rows. What it computes: [Judge](/reference/judge).

### `xdrcheck-judge --help`

```text
Ground truth from LedgerCloseMeta, and verdicts on indexer rows

Usage: xdrcheck-judge <COMMAND>

Commands:
  facts    Compute facts (JSONL) for ledgers; optionally run the conservation self-check
  verdict  Compare an indexer's rows with facts and emit verdicts
  help     Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
```

### `xdrcheck-judge facts --help`

```text
Compute facts (JSONL) for ledgers; optionally run the conservation self-check

Usage: xdrcheck-judge facts [OPTIONS] [FILES]...

Arguments:
  [FILES]...  Ledger files (zstd LedgerCloseMetaBatch or raw XDR), processed in the order given

Options:
      --root <ROOT>                  A lake-layout directory with `index.tsv` (seq, path, size)
      --list <LIST>                  Ledger sequences to take from --root (first column of each line; `#`/non-numeric skipped)
      --network <NETWORK>            [default: "Public Global Stellar Network ; September 2015"]
      --sac-registry <SAC_REGISTRY>  Extra SAC candidates: one asset string (`native`, `CODE:ISSUER`) per line
  -o, --out <OUT>                    Facts output (`-` = stdout). Omit to write none
      --conserve <CONSERVE>          Write `residuals.jsonl` and `summary.json` of the conservation check here
  -j, --jobs <JOBS>                  [default: 4]
  -h, --help                         Print help
```

### `xdrcheck-judge verdict --help`

```text
Compare an indexer's rows with facts and emit verdicts

Usage: xdrcheck-judge verdict [OPTIONS] --facts <FACTS> --rows <ROWS> --out <OUT>

Options:
      --facts <FACTS>                  
      --rows <ROWS>                    
  -o, --out <OUT>                      
      --balance-scope <BALANCE_SCOPE>  `net`: rows carry fees too; `nofee`: rows exclude fee and refund changes [default: net]
      --kinds <KINDS>                  Kinds to compare (default: every kind present in the rows)
      --roles <ROLES>                  Participant roles that count (default: all)
      --scope <SCOPE>                  The target's scope file (TOML): kinds, comparison modes, out-of-scope rules
  -h, --help                           Print help
```


## xdrcheck-tagger

Tag dangerous values in ledger bytes, partition by partition. What it computes: [The mainnet scan](/architecture/mainnet-scan).

### `xdrcheck-tagger --help`

```text
Tag dangerous values in ledger bytes

Usage: xdrcheck-tagger <COMMAND>

Commands:
  run    Tag every ledger of a lake-layout directory, one output set per partition
  merge  Join the partition outputs into the final files
  help   Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
```

### `xdrcheck-tagger run --help`

```text
Tag every ledger of a lake-layout directory, one output set per partition

Usage: xdrcheck-tagger run [OPTIONS] --root <ROOT> --out <OUT>

Options:
      --root <ROOT>              Lake-layout directory (`<partition>/<object>.xdr.zst`)
      --index <INDEX>            `seq<TAB>path<TAB>size` of the ledgers (default: ROOT/index.tsv)
      --out <OUT>                Output directory
      --jobs <JOBS>              Partitions worked at once [default: 8]
      --range <RANGE>            Only ledgers in a..b (inclusive)
      --row-cap <ROW_CAP>        Rows written per (tag, path) and partition [default: 5000]
      --passphrase <PASSPHRASE>  Network passphrase (SAC ids, transaction hashes) [default: "Public Global Stellar Network ; September 2015"]
      --check-size               Check each object's size against the index
  -h, --help                     Print help
```

### `xdrcheck-tagger merge --help`

```text

Usage: xdrcheck-tagger merge [OPTIONS]

Options:
      --out <OUT>  Output directory of `run` (one or more; partitions are joined in ledger order)
```
